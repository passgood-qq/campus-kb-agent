# C++ 语言程序设计

## 一、基本数据类型与修饰符

C++ 的基本类型包括 `int`、`char`、`float`、`double`、`bool`。`sizeof(int)` 在常见平台上为 4 字节，`sizeof(double)` 为 8 字节。

`const` 用于声明不可修改的量，编译期即可确定值的 `const` 可作为数组长度。`constexpr` 要求表达式在编译期求值。

引用是变量的别名，声明时必须初始化，且不能重新绑定。指针可以为空、可以重新指向，两者在语义上有本质区别。

## 二、类与对象

类是用户自定义类型，包含数据成员和成员函数。`public` 成员可被外部访问，`private` 仅类内可访问，`protected` 允许派生类访问。

构造函数与类同名、无返回值，支持重载。初始化列表 `: a(a), b(b)` 在进入函数体前完成成员初始化，对 `const` 成员和引用成员是必需的。

析构函数在对象生命周期结束时自动调用，用于释放资源。将析构函数声明为 `virtual` 的原因在于：通过基类指针删除派生类对象时，若析构函数非虚，派生类的析构函数不会被调用，造成资源泄漏。

## 三、继承与多态

C++ 支持单继承和多继承。`virtual` 函数实现运行时多态，通过虚函数表（vtable）在运行时确定实际调用的函数。

`override` 关键字用于显式声明重写，若签名不匹配编译器会报错，可以提前发现问题。`final` 阻止进一步继承或重写。

派生类构造时先调用基类构造函数，析构时先执行派生类析构，再执行基类析构。

## 四、内存管理

`new` 在堆上分配内存并调用构造函数，`delete` 释放内存并调用析构函数。`new[]` 必须配 `delete[]`，混用是未定义行为。

RAII（资源获取即初始化）是 C++ 的核心惯用法：把资源生命周期绑定到对象生命周期，构造时获取、析构时释放，从而避免手动管理带来的泄漏。

现代 C++ 推荐使用 `std::unique_ptr` 和 `std::shared_ptr` 管理动态对象。`unique_ptr` 独占所有权、不可拷贝只能移动；`shared_ptr` 通过引用计数共享所有权。

## 五、标准模板库

`std::vector` 是动态数组，随机访问 O(1)，尾部插入均摊 O(1)，中间插入为 O(n)。`std::map` 基于红黑树实现，查找、插入、删除均为 O(log n)，且按键有序。`std::unordered_map` 基于哈希表，平均 O(1)，但无序。

迭代器是容器与算法之间的桥梁，`begin()` 指向首元素，`end()` 指向尾后位置。

## 六、编译与链接

从源码到可执行文件经历四个阶段：预处理（展开宏与头文件）、编译（生成汇编）、汇编（生成目标文件）、链接（合并目标文件与库）。

`.h` 头文件通常放声明，`.cpp` 放定义。头文件需使用 include guard 或 `#pragma once` 防止重复包含。

模板在 C++ 中通常要求定义也放在头文件中，因为模板实例化发生在编译期。
