# Python 基础教程

## 一、变量与数据类型

Python 是动态类型语言，变量不需要声明类型，赋值即创建。基本数据类型包括整数 `int`、浮点数 `float`、字符串 `str`、布尔值 `bool`，以及表示空值的 `None`。

整数在 Python 3 中没有大小上限。浮点数遵循 IEEE 754 双精度标准，因此 `0.1 + 0.2 == 0.3` 的结果是 `False`，比较浮点数时应使用误差范围。

字符串是不可变对象，支持切片 `s[1:3]`、格式化 `f"{name}"` 等操作。常用的字符串方法有 `strip()`、`split()`、`join()`、`replace()`。

## 二、容器类型

列表 `list` 有序、可变，支持增删改查；元组 `tuple` 有序、不可变；字典 `dict` 以键值对存储，键必须可哈希；集合 `set` 无序且元素唯一，常用于去重。

需要注意的是，列表作为函数默认参数时只会在定义时创建一次，多次调用会共享同一个对象，这是 Python 的经典陷阱。正确写法是默认值设为 `None`，在函数体内判断后创建新列表。

浅拷贝 `copy.copy()` 只复制最外层容器，内部元素仍是引用；深拷贝 `copy.deepcopy()` 会递归复制所有层级。

## 三、控制流

条件语句使用 `if / elif / else`，依靠缩进划分代码块，缩进必须统一（通常为四个空格）。

循环有 `for` 和 `while` 两种。`for` 通常配合 `range()`、`enumerate()`、`zip()` 使用。`break` 跳出当前循环，`continue` 跳过本次迭代，`else` 子句在循环正常结束（未被 break 打断）时执行。

## 四、函数

函数用 `def` 定义。参数支持位置参数、默认参数、可变位置参数 `*args` 和可变关键字参数 `**kwargs`。

Python 的作用域遵循 LEGB 规则，即 Local、Enclosing、Global、Builtin。在函数内部修改全局变量需要 `global` 声明。

函数是一等对象，可以作为参数传递、作为返回值返回，这构成了装饰器的基础。装饰器本质上是一个接收函数并返回新函数的高阶函数。

## 五、异常处理

异常处理使用 `try / except / else / finally` 结构。`except` 可以捕获指定类型的异常，`else` 在没有异常时执行，`finally` 无论是否发生异常都会执行。

捕获异常时应尽量指定具体类型，避免使用裸 `except:`，否则会吞掉包括 `KeyboardInterrupt` 在内的所有异常，导致难以排查问题。

使用 `raise` 主动抛出异常，`raise ... from ...` 可以保留原始异常链。

## 六、文件操作

推荐使用 `with open(path, mode, encoding="utf-8") as f:` 的形式，`with` 会在代码块结束时自动关闭文件，即使中途抛出异常也不会泄漏文件句柄。

读取大文件时应逐行迭代，而不是一次性 `read()` 全部内容，避免内存占用过高。

## 七、模块与包

一个 `.py` 文件就是一个模块，包含 `__init__.py` 的目录是包。`if __name__ == "__main__":` 用于区分“直接运行”和“被导入”两种场景。

## 八、虚拟环境

使用 `python -m venv .venv` 创建虚拟环境，激活后 `pip install` 安装的依赖只作用于当前环境，避免不同项目的依赖互相污染。
